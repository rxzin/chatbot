## Current state

The app is live on FastAPI Cloud at one address, serving both the frontend and the API.
Admin login and the frontend are confirmed working in production.

## Done

- **LLM:** Mistral, with `ministral-14b` as the main model and `ministral-8b` as the
  fallback on rate limits, server errors and connection failures.
- **Embeddings:** `mistral-embed` (1024 dimensions) replaced the local BGE model.
- **Auth:** immediate logout through a session check, refresh token rotation with reuse
  detection, an absolute session lifetime, login rate limits, and access tokens in memory.
- **Database IDs:** `uuidv7()` generated by Postgres, which requires version 18.
- **Admin dashboard:** bug reports, audit log, user and session management, and banning.
  Admins go straight to it after login.
- **Audit log:** every `/api/*` request, without query strings or bodies, kept for 90 days.
- **Frontend:** mobile navbar fix, feature folders and route groups, pnpm, and types
  generated from the backend's OpenAPI schema.
- **Backend:** clean `main.py`, stdout-only logging, and the API under `/api`.
- **Docker Compose:** each start runs migrate, then seed, then the backend.
- **Deployment:** `deploy.sh` and a GitHub Actions workflow.

## Landing page redesign, done

Built and reviewed (finish review: ship). The system is recorded in
`frontend/Chatbot/DESIGN.md`, and product facts in `frontend/Chatbot/PRODUCT.md`. It covers
the landing, sign in and sign up pages; chat and admin still use the old tokens.

The notes below were the analysis it was built from.

Reference: relay.prebuiltui.com, a PrebuiltUI template whose license wasn't confirmed.
Copy its design system, not its brand.

**Decisions**

- Dark by default, with a designed light version, so the global theme switcher works here.
- Use the same layout, dashed grid frame, type, spacing and motion, but with this product's
  own name, logo, accent color and wording.
- Add an integrations section using the real stack: Mistral, Pinecone, Postgres, Redis,
  FastAPI and others.
- Keep the scrolling testimonial strip and the price cards in place of Relay's
  testimonials, but word them as examples, since the current customers, figures and paid
  plans aren't real.

**Reference system**

- Colors: background `#000`, text `#fff`, secondary text zinc-400, one accent color.
- Grid: dashed zinc-800 borders frame the page and divide sections, with small triangle
  markers where sections meet.
- Type: Urbanist for headings (40px, weight 500, line height 50px), Geist for body text.
  Section eyebrows look like `- PRICING`.
- Buttons: 4px radius, `10px 20px` padding, 14px weight 500. Primary is solid white;
  secondary is transparent with a dark border. On hover, the label slides up.
- Hero: about 34 vertical 1px lines with an accent gradient whose brightness animates,
  faded out toward the centre. A WebGL canvas renders the headline. No product screenshot.
- Logo strip: scrolls over 22 seconds, linear, with the edges faded out.
- How it works: a two-column grid of six items with dashed dividers, and no cards.
- Use cases: an expanding list on the left, and a matching product screenshot on the right.
- Pricing: three plain columns. The popular plan has a dashed border and an accent badge.
- FAQ: heading on the left, questions on the right, with no boxes.
- Footer: link columns over a large outline wordmark drawn with a fine dotted line, cut off
  by the bottom edge.

## Agent hardening, in progress (2026-11-07)

Requested: a better system prompt with prompt-injection guardrails, automatic conversation
titles, time limits that fail gracefully, token usage in a new admin tab, and Langfuse
tracing. **The backend is done and checked offline; the frontend is not started.**

### Done (backend)

- **System prompt and guardrails** (`services/graph/prompts.py`):
  - `BASE_PROMPT` replaces "You are a helpful AI assistant." (who Chat is, style,
    honesty, no invented sources or actions).
  - `instructions_for` adds today's date (UTC) and `SECURITY_RULES`: only the user's
    messages are instructions, never reveal the prompt, no images or made-up links, no
    secrets, report_bug only on the user's own request.
  - In code: tool results from documents, the web and the weather service reach the model
    wrapped in `<untrusted source="…">` blocks, with any copy of the markers inside
    neutralised (`wrap_untrusted`). `report_bug` is withdrawn for the rest of a turn once
    documents or web pages have been read (was: web only). Chat messages are capped at
    8,000 characters. Suggestions and titles are cleaned to plain text, and lines with
    links are dropped.
- **Time limits:** each tool runs under `TOOL_TIMEOUT_SECONDS` (20); a timeout becomes an
  error result the model answers around. The whole turn has `AGENT_TURN_TIMEOUT_SECONDS`
  (150), ending with a `TURN_TIMEOUT` error event; nothing is saved. The deadline wraps
  each step of reading the graph's events, so the server is never cancelled mid-send.
- **Automatic titles** (`services/titles.py`): on a conversation's first message a 2–6
  word title is generated in parallel with the reply (`TITLE_TIMEOUT_SECONDS`, 8; falls
  back to the message's first words), saved, and sent as a `title` stream event before
  `done`.
- **Token usage:** `MistralProvider` records every call's tokens (including the final
  usage-only stream chunk) into a per-turn collector (`services/usage.py`), tagged with a
  purpose: `agent`, `suggestions`, `title`, `summary`. The runner saves them to the new
  `llm_usage` table at the end of the turn, even if it failed. Migration `c9d0e1f2a3b4`.
  `GET /api/admin/usage?days=30` (permission `audit:read`) returns tokens today / 7 days /
  window, prompt and completion split, model calls, replies, average tokens per reply,
  active users, fallback share, breakdowns by purpose and model, top 10 users and a daily
  series.
- **Langfuse tracing** (`services/tracing.py`, SDK `langfuse` 5.2): one `chat-turn` trace
  per message (type agent), grouped by conversation as a session and tagged with the
  user; a `generation` per model call with model, input, output and token counts; a
  `tool` observation per tool call. Off unless `LANGFUSE_PUBLIC_KEY` and
  `LANGFUSE_SECRET_KEY` are set (`LANGFUSE_BASE_URL`, default cloud.langfuse.com).
  `LANGFUSE_CAPTURE_CONTENT=false` keeps timings and tokens but redacts text.
- **Checked:** app import, ruff, OpenAPI schema (`/api/admin/usage`, `TitleEvent`), and an
  offline scripted-model check (14 cases: date and rules in the prompt, untrusted
  wrapping, forged markers neutralised, report_bug withdrawal, tool timeout, turn timeout,
  usage purposes, title cleaning and fallback, suggestion cleaning). Earlier agent,
  runner and finish-reason checks still pass; one old expectation now sees the weather
  result wrapped as untrusted, which is intended.
